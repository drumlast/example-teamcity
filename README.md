## 6. Ошибка сборки `clean deploy`
(/img/06.png)
### Причина ошибки
Nexus **запрещает перезаписывать артефакты** в `maven-releases`, а версия в `pom.xml` была **одинаковой с уже существующей**.

### Решение
- Повышение версии в `pom.xml` → **0.0.3**.
